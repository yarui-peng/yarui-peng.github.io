# E3DA Lab public website

This repository contains the public Astro website for E3DA Lab. It is static-only and safe to deploy to GitHub Pages or Cloudflare Pages.

## Development

```sh
npm ci
npm run dev
npm run build
npm run preview
```

Private manuals, software release files, LDAP credentials, OIDC secrets, and the internal Astro SSR site are maintained in a separate deployment and are not part of this repository.
